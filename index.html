ℹ️ O que é este exercício de Back-End?

Esta atividade não possui uma página visual em HTML porque foi feita para rodar diretamente no servidor / terminal (com Node.js). O objetivo foi exercitar lógica de programação, classes e manipulação de dados. Você pode analisar todo o código-fonte desenvolvido no painel à esquerda!

Guia Rápido: O que significa cada tecnologia?

  • HTML O Esqueleto: Define os textos, títulos, campos, botões e imagens da página.
  • CSS A Decoração: Cuida das cores, fontes, espaçamentos e beleza visual.
  • JavaScript O Cérebro: Dá vida e movimento à página, respondendo aos cliques e formulários.
  • Node.js O Motor de Bastidores (Back-End): Processa dados no servidor e faz contas sem precisar de tela.
